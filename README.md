# Audiobook Speed Calculator

A small, dependency-free static page for estimating audiobook listening time, progress, and a local finish date.

## Preview locally

From the project root, run:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

Then open <http://127.0.0.1:4174>.

The root `index.html` uses native HTML, CSS, and JavaScript modules. It has no backend, build step, or third-party runtime requests.
